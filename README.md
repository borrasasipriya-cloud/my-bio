# Alex Morgan Portfolio

A responsive, dependency-free portfolio built with semantic HTML, CSS, and vanilla JavaScript. Personal details, links, project descriptions, portrait, and resume are illustrative placeholders; replace them before publishing.

## Run locally

Open `index.html` in a browser. For local server behavior, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Customize

- Update the name, biography, contact address, links, education, and project content in `index.html`.
- Replace the portrait and project image URLs with your own assets.
- Replace `assets/alex-morgan-resume.txt` with your resume and update the download link in `index.html`.
- Edit theme colors, layout, and responsive styles in `styles.css`.

Project imagery and web fonts load from external providers, so an internet connection is needed for those assets. All page layout and interactions work without a build step.
